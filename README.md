# Вебинары Высшей инженерной школы

[Открыть каталог вебинаров](https://zhidandbor.github.io/academy-hes-webinars/) · [Главная библиотека Academy](https://zhidandbor.github.io/academy/) · [Основные курсы HES](https://zhidandbor.github.io/academy-hes/) · [Миникурсы HES](https://zhidandbor.github.io/academy-hes-mini/)

Публичная страница содержит 13 прошедших вебинаров Высшей инженерной школы. Карточки ведут по прямым ссылкам на соответствующие записи на Rutube. Фотографии спикеров, оформление и поиск включены в этот репозиторий.

GitHub Pages публикует ветку `main`, папку `/docs`. [Состав выпуска и SHA-256](docs/release.json) позволяют сверить опубликованные файлы с исходным архивом HES. Рабочие реестры и скрипты сборки остаются в приватном исходном репозитории.

Текущий выпуск проекта ВИШ завершён 7 октября 2026 года. Каталог будет обновляться при появлении новых вебинаров. [Исходный архив и проверки](https://github.com/zhidandbor/HES/tree/main/course_offline/webinars_past) доступны владельцу приватного репозитория HES.
